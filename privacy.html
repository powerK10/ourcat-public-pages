PRIVACY POLICY

Your information in OurCat.

OurCat is published under the developer name mycatapps. Contact mycatapps@gmail.com with privacy questions.

Last updated: 13 October 2026. These pages describe the intended private Android closed-test service.

What you provide

Email/password account details; cat profiles and practical information; care records and optional notes; reminders and preferences; carer names, contact details and invitations; and optional photos. Enter only information you are comfortable sharing with the authorised carers of that cat.

Outdoor records may contain a location description you type. OurCat does not use a device-location service for that feature. The current Android beta offers email/password sign-in; Google sign-in is deferred.

Information used to run the service

The app generates identifiers, timestamps, the cat’s home timezone, membership and access state, reminder completions, upload metadata and deletion-request status. Firebase services may process account and installation identifiers, IP addresses, app/SDK information and a notification-delivery token.

Limited account-scoped state can be stored locally, including unfinished care writes and reminder preferences. A care write queued on the phone may later synchronise to the cloud when connectivity returns.

Why we use it

To secure accounts, keep care records, show the right cat, share care with authorised members, deliver requested reminders, store optional images, enforce access and limits, answer support requests and process deletion. We do not use care content for advertising.

Who can see it

Authorised carers can see relevant cat information under household roles and access controls. Some information and operations are owner-only. Temporary access is time-limited.

Firebase Authentication, Cloud Firestore, Firebase Storage, Cloud Functions and Firebase Cloud Messaging provide the app’s authentication, storage and delivery infrastructure. Support messages are handled through the public support mailbox. These providers have their own technical/security processing and terms.

Crash reporting and analytics

Crash reporting stays off for the first closed-test cohort. Firebase Analytics is not used. Any later optional crash-reporting programme will need a separate explanation and an individual choice before collection starts.

Retention and deletion

We keep information only while it is useful for providing the account, shared care and necessary service operation. We do not choose additional retention simply because information might be useful someday. Unneeded information should be deleted or anonymised.

You can start an account-deletion request in Settings → Account & privacy, or request it here without installing the app. Following identity verification and the applicable shared-care process, eligible account records and personal identity links are removed or pseudonymised. Shared care history may remain for other authorised carers.

A shared-owner request can enter the existing 14-day survival window. We will explain any shared-ownership steps that affect completion. Deletion is a request and is not necessarily immediate. We will not delay verified requests unnecessarily.

If a specific legal or necessary service exception requires retention, we keep only what is needed for that purpose and explain the exception where permitted. Technical service-provider information is subject to the provider’s applicable retention and security terms.

Security

Account access is authenticated, and shared information is restricted through role and access controls. Use a secure account password and share invitations only with the intended carers. Do not enter information you do not want authorised carers to see.

Website hosting

The intended host is GitHub Pages. GitHub logs visitors’ IP addresses for security when serving Pages sites. This website adds no analytics, advertising or submission form.

Your questions and choices

Contact mycatapps@gmail.com to ask about, correct or request removal of information associated with your account. We will verify the request using the minimum information needed. Never send your password.
